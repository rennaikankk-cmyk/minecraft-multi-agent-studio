# 无政府服务器自主生存流程（Anarchy Autonomy Runbook）

目标：一台无规则服务器（对手是外挂/客户端用户），一个 Bot 只靠
`purpose: "anarchy"` 的 ServerProfile 接入后，**不需要任何人工提示词**
即可长期生存、发展、防御与恢复；人给出的提示词只是可选的方向盘。

## 1. 强度立场

无规则服没有反作弊、没有封号风险，本项目为此拆掉了所有"自保式"边界，
只保留两条**存活安全**约束（防把岩浆/水引进家、防被沙砾活埋——它们与
反作弊无关）。对照表：

| 边界 | 原行为 | 无规则行为 |
|---|---|---|
| 导航 | 不沿途挖掘/不跑酷/不搭塔/限 2 格下落 | `navigation: "anarchy"`：canDig、疾跑、跑酷、1x1 搭塔、搭路（自动消耗背包 cobblestone/dirt/planks/netherrack）、4 格下落 |
| 采集半径 | 32 格 | **64 格**（findBlocks 有 count 截断，稀疏目标才吃满扫描面积） |
| 扫描半径 | 64 格 | **96 格** |
| 采集批量 | 32 | **64** |
| 别人的熔炉 | 拒绝使用（FURNACE_NOT_EMPTY） | **先掠夺后使用**：取走炉内产物/在烧物/燃料，再投入自己的 |
| 觅食动物 | cow/pig/rabbit/sheep | + **chicken** |
| 应急口粮 | 腐肉不算食物 | **腐肉入列**（饥饿 debuff 不掉血；effectiveQuality 排序天然最后选） |
| 服务器地址 | 仅回环/内网 | `purpose: "anarchy"` 允许 **公网** 地址（裸 IP 或 DNS 名） |
| 攻击距离/CPS 等每动作参数 | 原版机制内自限 | **保持不变**——那不是反作弊让步，是原版服务端本身的校验，越界动作会被服务端丢弃 |

## 2. 一次性部署

```powershell
# a) 复制并改好 profile（host/username/whitelist 至少要改）
Copy-Item .\configs\servers\anarchy.example.json .\configs\servers\anarchy.local.json

# b) Spark 已在 .env.local 配好（vLLM, ornith15-heretic, 12 路并发）。
#    不配 Spark 也活：基础生存链 0 次模型调用。

# c) 启动
pnpm start
```

单 Bot 手工验收模式：

```powershell
$env:BOT_SERVER_PROFILE_PATH="$PWD\configs\servers\anarchy.local.json"
pnpm bot:start
```

## 3. 无提示词的自主循环（不需要人做任何事）

```
登录 → 需求评估（survival-needs，纯确定性）
  ├─ 食物安全：曲线升权；food.secure 觅食（掉落物→作物→被动生物→探索）
  ├─ 工具阶梯：木→石→铁→钻石镐；耐久 <20% 提前补备用
  ├─ 武器/护甲/盾牌：逐件补齐；有甲未穿先穿（equip-armor）
  ├─ 储备：木 16 / 煤 8 / 铁 6 / 火把 16
  ├─ 避难所：受伤时 72 分（徒手挖土即可），平时石铁期补
  ├─ 钻石推进：铁镐后 3 钻起步 → 钻镐/钻剑/钻甲
  └─ 探索：扇区递增（48/96/160/224），按 botId 哈希错开方向
失败 → 有界恢复梯（扫描→接近→重试→换区）
3 连败 → 抑制 120s → 【Spark 神谕】从白名单菜单选替代策略
受伤/夜间 → L0 反射层（进食/撤退/挖洞/战斗/断线保号+60s 退避重连）
死亡 → 取消全部技能 → 自动重生 → 空背包自然重推导需求
背包满 → 白名单丢垃圾（永不丢工具/食物/矿/装备）
```

## 4. 人给提示词的方式（全部可选）

1. **Dashboard 自由目标**：`/v1/goals` 输入自然语言（如"去下界采远古残骸"），
   走模型分支，输出仍受 schema + 确定性规划器双重约束。
2. **重规划神谕**：无需操作。需求 3 连败时 Spark 自动被咨询一次
   （4 选 1 白名单策略 + 白名单替代品；劫持也无法越权）。
3. 未来：多 Bot 战略分工（同约束菜单模式）。

## 5. 已知未完成

- 正版账号（online-mode）认证：profile 仍是 `auth: "offline"`。多数无政府服
  要求正版——需要账号凭据流（凭据只进环境变量/私密文件，绝不入 profile）。
  这是上公开无政府服前的最后一道门。
- 死亡掉落回收目标（回死亡点捡装备）：死亡恢复会重推导基础需求，但不会
  主动回死亡点；价值判断（距离/风险）适合做成一个 Spark 神谕菜单项。
- 战斗主动出击策略（现在 stance=preserve-life 防御优先）。
