5. 操作纪律（踩坑记录）

  • 中文 goal 一律文件方式：node JSON.stringify → tmp-goal.json → curl --data-binary @file + charset=utf-8（bash 内联必乱码）
  • goal timeoutMs ≤ 120000：协议 schema max，超了 INVALID_REQUEST
  • 测试前 peaceful+day：怪物围攻+异步 chunk = bot 死循环
  • goalPreview 不进日志：隐私测试断言 operator goal 不出现
  • 不要内联 node -e 写复杂内容：模板字面量必炸，用 Edit 工具
  • rcon tp 前确认 chunk 已加载：异步 chunk = 永久 FALLING
  • 测试服世界重置：docker rm -f studio-local-test-mc + volume rm studio-local-test-data + manager start
  • push 网络断连：等 30-60 秒重试即可恢复
