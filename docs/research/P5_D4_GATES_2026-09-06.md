## Original D4 Gates

- Independent feature flag, default OFF; flag OFF retains the existing safe path.
- Provider queries Rust asynchronously and synchronous readers receive the latest completed snapshot with generation/freshness/scope/completeness.
- Concurrent consumers share the actual in-flight Promise; no synchronous wait, duplicate refresh or Dashboard-triggered scan.
- NORMAL never runs the legacy comparator. LOCAL_TEST/E2E may explicitly compare identical queries in stable/recheckable windows.
- Compare the original 24 interests, positions, distance/count and stable ties; separate world changes, unloaded/incomplete data and oracle limitations from confirmed mismatches.
- After oracle validation, enabled NORMAL data source performs zero periodic findBlocks x24 scans.
- Updates become visible within the normal batch plus measured queue time; overflow/gaps never silently drop data.
- Cancellation, reconnect, dimension change, worker failure and bounded recovery cannot publish old results or invent empty worlds.
- Preserve local server-confirmed action readbacks. P5-E A* mirror consumption is separate and is not claimed complete.

The broader Phase 5 targets remain snapshot build P99 <=10ms, physicsTick.stateChanged P99 <=15ms and event-loop P99 target <=25ms. ## Implementation and Local Evidence

- `STUDIO_WORLD_QUERY_PROVIDER=1` enables the candidate; default OFF retains the original scanner. All rows marked D4 above are connected in `mineflayer-client.ts`, `runtime.ts` and `navigation-process-adapter.ts`.
- Provider admission is bounded (one active query, queue8, cache16), identical callers share a Promise, native work stays asynchronous. Snapshots carry original capture time, revision, generation and explicit completeness. Utility telemetry preserves each block's `lastSeen`.
- Supported action queries use the index plus fresh local block/reach readbacks. Names outside the 24-selector registry get an on-demand compatibility probe at most once/second, radius16/count64; that probe never proves complete coverage. No periodic legacy fallback is used.
- The batched `matching:each` preserves top8 for every interest in one sparse traversal; family selectors receive exact name filtering for action requests.
- `STUDIO_WORLD_QUERY_SHADOW=1` requires `STUDIO_MODE=LOCAL_TEST` or `E2E`; NORMAL ignores it. Bounded evidence separates match/mismatch, changed observations, incomplete coverage, truncated legacy oracle and oracle errors. Replay frames contain query bounds, epochs, source revision, coverage, both point sets, distances and selector masks.
- Cancellation, old scope results, clock reversal, stale cache, worker errors, incomplete worlds and timeout admission have focused tests; real native/Worker tests include the batched selector mode. Restart is bounded and retains the original scope isolation.
- Real server testing found and fixed two inherited D2 wiring defects: Prismarine World3.7 `getColumns()` returns string map keys, and old failed batches could repeatedly reset a newer session. Coordinates are normalized before N-API, callback identity is checked, and an adapter stops after two failed recovery cycles.
